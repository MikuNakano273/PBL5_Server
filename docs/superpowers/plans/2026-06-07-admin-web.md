# Admin Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and serve a bilingual React administration SPA for the existing `/api/admin/v1` FastAPI endpoints.

**Architecture:** A Vite React TypeScript application in `admin-web` owns browser routing, session authentication, localization, API calls, and responsive admin pages. FastAPI serves `admin-web/dist` under `/admin`, with an SPA fallback and an informative missing-build response.

**Tech Stack:** React 19, React Router, Vite, TypeScript, Vitest, Testing Library, FastAPI, Starlette, Python unittest

---

## File Structure

- `admin-web/src/api/`: typed documents, HTTP client, and admin endpoint functions.
- `admin-web/src/auth/`: session token storage and protected-route behavior.
- `admin-web/src/i18n/`: VI/EN dictionaries, language persistence, and translation context.
- `admin-web/src/components/`: shared feedback, table, pagination, badge, and dialog primitives.
- `admin-web/src/layout/`: authenticated sidebar/top-bar shell.
- `admin-web/src/pages/`: login, dashboard, users, devices, image requests, and alerts.
- `admin-web/src/test/`: browser test setup and API fixtures.
- `api/app/admin_web.py`: static asset mount and SPA fallback registration.
- `api/tests/test_admin_web.py`: server integration coverage.
